# GCSE Computer Science – Topic 5: Issues & Impact

An interactive revision website for Pearson Edexcel GCSE Computer Science (9-1) Topic 5: Issues and Impact (pp.61–72).

## Features

### 📖 Revision Notes
- 7 sub-topics covering Environmental Issues, Personal Data & Privacy, Legislation, Artificial Intelligence, Intellectual Property, Cyber Threats, and Protection Methods
- Click any topic button to view detailed notes

### 📝 Quiz Mode
- 10 random questions per round
- Covers all topics or select specific ones
- Instant feedback with correct answers shown

### 🏰 Tower Defense Game
- Build towers (Firewall, Antivirus, MFA, Encryption, IDS, Zero-Trust, etc.)
- Defend against waves of malware (Viruses, Worms, Trojans, Ransomware)
- Use power-ups (Freeze, Slow, Clear, Coin Rain, Repair, Boost)
- Answer quiz questions to earn bonus coins

### 💾 Byte Clicker
- Incremental clicker game about data storage
- 20+ upgrades (Stronger Click, Auto Clicker, Critical Hits, Combo System)
- Prestige system with multiplier bonuses
- Random events (Data Surge, Malware Attack, Lucky Click, Click Frenzy)
- Daily login bonus and achievements

### 👾 Maze Quiz Challenge
- Pac-Man style maze game
- Eat dots and power pellets
- Answer quiz questions at corner "?" tiles to clear rounds
- 5 difficulty levels with increasing rounds

### ⚔️ Two-Player Battle
- Clash-Royale style card battler
- 10 unique cards per player (Cyber Security vs Malware)
- Deploy units and spells on the battlefield
- Play against AI with 5 difficulty levels (Easy to Impossible)
- Answer quiz questions to gain bonus energy

### 📚 Flashcards
- 30+ glossary terms with definitions
- Mastered cards are removed from rotation
- Progress saved locally

### 🎨 10 Visual Themes
- Dark, Light, Neon, Retro, Forest, Ice, Ocean, Ember, Monochrome, Pastel
- Theme selection saves to browser storage

### 📊 Statistics Tracking
- Tracks total quiz questions answered and accuracy
- Saves highest Tower Defense wave
- Records clicker lifetime bytes
- Stores Maze Rush max round

### 🤖 Study Helper
- Mastery system (answer 5 questions correctly per topic to unlock next)
- Weakness analyzer shows which topics need more revision
- Spaced repetition for quiz questions
- Daily fact footer with cybersecurity trivia
- Animated mascot with helpful tips

## How to Run

1. Save the file as `index.html`
2. Open in any modern web browser
3. Data saves automatically to your browser's local storage

## File Structure

- Single HTML file (CSS + JavaScript included)
- No external dependencies required
- Works offline after first load
